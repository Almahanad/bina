# دفتر بناء

تطبيق عربي لتسجيل فواتير مشروع بناء المنزل ومتابعة ميزانيته. يعمل على الهاتف بدون إنترنت بعد أول فتح، وكل البيانات تبقى في جهاز المستخدم ولا تُرسل إلى أي خادم.

**التثبيت على الآيفون:** افتح رابط الموقع في سفاري ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

---

An Arabic app for tracking a home-construction project's invoices and budget. Works offline after the first visit; all data stays on the user's device.
